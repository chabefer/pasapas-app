# PasAPas — Revenge of the Gorns

A single-file, no-dependency web app teaching area, perimeter, and multiplication
through a story: Eliel the elf replants burned forest fields, computing seeds (area)
and wire (perimeter) as they go.

**Play it:** https://chabefer.github.io/pasapas-app/

Part of the [PasAPas](https://github.com/chabefer) project — preserving neoteny in
learning: symbolic notation is introduced only when the child feels the need for it.

## Notes

- Single `index.html`, pure HTML/CSS/JS with inline SVG. No build step, no dependencies.
- Touch-friendly — works on tablet browsers.
- Debug step-jump menu: append `?debug` to the URL.

*Chapter 1 of a planned series. Chapter 2 ("The Power of the Root" — square roots) is next.*
